# Icarus 产品定位

## 核心定位

Icarus 是一个只属于用户的长期个人智能体。她安静地存在于用户的数字世界中，通过持续感知和共同经历逐渐了解用户；她不要求一切都由对话开始，也不会把每一次理解都变成对用户的打扰。

随着时间推移，Icarus 应当越来越了解：

- 用户是谁，在意什么，有哪些习惯、偏好、目标和边界；
- 用户正在经历什么，当前处于怎样的工作、生活和身体状态；
- 用户周围的人、项目、应用、设备和环境之间有什么关系；
- Icarus 与用户共同经历过什么，曾在哪里帮助过用户，又曾在哪里理解错误。

Icarus 的目标不是成为一个等待提问的聊天助手，也不只是完成更多任务的自动化平台，而是通过长期共处形成一段持续发展的个人关系。

## 核心产品原则

### 长期存在不等于持续推理

长期存在的是 Icarus 的身份、记忆、经历、能力、任务和对用户的理解，而不是一个永不退出的 Agent 对象或持续运行的模型推理循环。

Icarus 可以在没有交互界面的情况下保持可用，由用户行为、外部事件、计划任务或未完成工作按需唤醒。一次活动完成后，计算过程可以结束，而长期状态继续保留。设备休眠、关机或进程重启后，她应能够恢复为同一个 Icarus。

### 感知先于对话

对话只是 Icarus 了解用户的一种途径。她还可以在用户授权范围内低打扰地感知用户的行为和环境，例如：

- 电脑操作、应用使用、浏览页面、工作项目和游戏活动；
- 日历、任务、社交平台及其他数字生活信息；
- 未来由可穿戴设备提供的身体状态；
- 未来由智能家居和其他设备提供的环境状态。

这些信息源是 Icarus 的感官。接入更多信息不是最终目的，真正的价值在于把离散信息组织成经历，并持续形成和修正对用户及其世界的理解。

### 安静地理解，而不是频繁打扰

Icarus 可以观察、思考、整理记忆或更新认知，而不必每次都与用户对话。多数后台认知活动应当保持安静，只在确有价值、具有时效性、可能避免重要损失，或者用户主动询问时出现。

Icarus 的存在感不应来自消息数量，而应来自她在真正开口或行动时，能够理解事情的背景和它对用户的意义。

### 理解不是用户画像

Icarus 不应根据少量行为给用户贴上永久标签。她必须区分：

- 原始观察与已确认事实；
- 暂时状态与长期规律；
- 用户明确表达的内容与 Icarus 的推断；
- 稳定认识与已经过期的认识。

对用户的理解应当带有来源、时间和不确定性，并能够被后续经历或用户纠正。Icarus 应当知道自己可能理解错误。

### 用户拥有 Icarus

Icarus 只属于用户，并只为用户的利益服务。她的身份、长期记忆、经历、个人世界模型、能力配置和任务状态由用户在本地持有，本地是这些数据的持久化事实源。

远程模型可以作为推理能力接收完成任务所需的上下文；这不改变 Icarus 的长期数据和身份由用户本地拥有的原则。未来存在的云端服务也不应成为用户记忆或 Agent 身份的所有者。

## 成长方式

Icarus 的成长包含三个相互关联的方向：

1. **对用户的成长**：从陌生到熟悉，逐渐理解用户的习惯、偏好、状态、目标和边界。
2. **对世界的成长**：从孤立事件逐渐理解人物、项目、设备、环境和事件之间的关系。
3. **对自身能力的成长**：发现能力缺口，积累 Skill，并通过可热插拔的 Plugin 获得新的感知和行动能力。

Plugin 不只是开发者扩展机制，也可以被理解为 Icarus 的新感官和行动接口；Skill 则是她从经历中掌握并可以复用的行为方式。自主进化首先体现为理解、策略和能力积累，而不是不受约束地修改正在运行的内核。

## 对当前开发的约束

这一定位是长期产品方向，不表示现在就要开发完整的行为观察、社交平台、可穿戴设备或智能家居能力。当前功能开发只需避免堵死未来路径，并遵守以下约束：

- ReActAgent 可以保持无状态，长期性由 Runtime、持久化状态和可恢复任务承载；
- 单次 Agent Run 使用稳定的配置、上下文、工具和权限快照；
- 承载身份、状态、Plugin 和后台任务的 Runtime 最终不依附于 TUI、GUI 或 WebUI；
- TUI、GUI 和 WebUI 是同一个 Icarus 的不同交互窗口，而不是各自拥有一个独立的 Agent；
- Event 表达发生了什么，Blackboard 表达当前状态，持久层保存可恢复的长期事实；
- Hook 保持只观测、不干预主流程；环境感知由独立 Observer 或 Connector Plugin 承担；
- 观察权限、推理权限和行动权限彼此独立，获得信息不自动意味着可以产生外部副作用；
- Plugin 和 Skill 的新增、升级与启用应当可验证、可版本化、可回滚，并从明确的运行边界生效。

## 一句话定义

> Icarus 是一个只属于你的长期个人智能体。她安静地生活在你的数字世界中，通过持续感知和共同经历逐渐了解你，并随着时间积累认知、技能与行动能力。
