# 端到端产品体验与对象生命周期 TODO

## 目标

完善用户从输入 `icarus` 命令，到最终内容展示完成或程序退出的完整使用体验。重点不是建立
一个新的全局生命周期管理器，而是让各层对象的所有权、状态、终态、清理和用户反馈能够在
同一条产品链路中正确衔接。

## 生命周期对象清单

进入对应阶段时，基于当前代码继续确认并补齐以下对象：

- 命令进程与 Textual 应用壳层；
- Agent Runtime 与 Session；
- Composer 草稿、TUI 本地待发送队列和已接受输入；
- Agent Task / Run 与每个 Model Step；
- Tool Call 与其结果、失败、超时和取消；
- Runtime Event、输出订阅、TUI Projector、UI Action 与消息组件；
- 流式输出段、最终结果和退出清理任务。

## 每类对象需要回答的问题

- 谁创建、拥有和结束该对象，其他层可以做什么；
- 对象何时可用，具有哪些稳定状态和唯一终态；
- 正常、失败、取消、超时、重试和进程退出时如何转换；
- 哪些状态必须展示给用户，哪些只属于内部观测；
- 如何关联同一条链路中的 Session、Task、Step、Tool Call 和 UI 投影；
- 资源、Worker、订阅、文件和后台任务何时清理，清理失败如何反馈；
- 哪些内容可以恢复或重试，以及如何避免重复提交和结果歧义。
