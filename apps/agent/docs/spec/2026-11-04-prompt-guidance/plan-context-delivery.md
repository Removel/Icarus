## 资料归属与证据边界

用户提供的根目录调研文件迁入 [reference-codex-research.md](reference-codex-research.md)，保留原文作为 Agent 方案参考。它不是仓库基础设施设计，也不涉及多个应用的不可拆分需求。其源码基线与 Icarus 不同，不能直接当作 Icarus 的实现事实。

可采纳：稳定前缀、按能力披露、执行器语义写入工具契约、动态事实保留来源和边界、整节预算及恢复测试。

需收紧：稳定消息 ID 不保证服务商缓存命中；增量消息不等于服务端不再计算历史上下文；搜索不到直接引用不能证明文件必然是导出样本；提示词长短不能证明训练能力或质量；文本/JSON 包装只能提示模型区分数据，不能替代执行层授权检查。Icarus 不复制 Codex 的 provider 专属 developer 消息、catalog、WorldState 或权限审查器。

## 实施范围

1. 框架维护的 base、插件指导、工具/字段描述、任务联网提示、记忆包装、摘要、标题生成、JEV 判据和内置默认人格统一英文。用户当前语言决定回复/标题语言；不翻译用户正文、工作区规范、自定义人格、Skill 正文、第三方 MCP 描述和外部事实。
2. System 保留稳定共通规则、短能力发现/维护触发规则、人格核心和私有指令。删除启动时的 Skill 轻量目录采样（旧版也没有预注入正文），按需 list/search/read，避免目录快照陈旧和每轮固定负担。
3. 可选插件通过应用层契约提供工具范围指导；SessionRuntime 采样并将普通字符串交给 core 的工具目录。`tool_search` 返回完整范围指导与工具定义，仅在两者均完整保留时授予该 Run 的加载状态；core 不导入应用插件或 Prompt 契约。
4. Persona 人物关系事实不再在会话初始化时进入 System，按任务刷新并进入当前 User 上下文；演化观察作为会话冻结的背景数据进入 User，核心身份/边界和演化可用性保持稳定。防御仍条件触发，防御预算和总 Prompt 预算不放宽。
5. WebSearch 只在本轮 User 上下文报告时间、开关和查证深度，工具具体调用/来源规则在加载时交付。Memory 自动召回继续使用既有 Event/ACK 路径，不复制到 System。

## 验收

以 WSL 为准：先工具目录/加载完整性、Prompt/Persona/Memory/Skill/WebSearch 聚焦测试，再 Agent 全套与 Gateway 相关测试，编译、diff 和链接检查。记录完整 System/User/工具定义/首次搜索/后续轮次各项成本，保守预算与 tokenizer 估计分开；不根据英文单词或字符数宣称实际线上 token 净节省。运行真实模型需使用隔离场景并记录配置，离线断言不等于行为已通过。

本轮不自动提交、推送或创建 PR；不改本地服务凭据、数据目录和用户其他工作区改动。实施结论及测量将在本文件后续追加。

## 采用边界和后续验证

本轮完成语言、规则所有者、注入位置/时机和协议完整性调整。没有照搬Codex消息角色或引入新的WorldState/隐藏权限层。稳定前缀只保证应用产出的System不随普通任务改变，不承诺远端缓存。

每任务Persona关系刷新是显式启用时的后台读取，会增加读取次数；它不是模型主动调用relationship工具，也不会被“不为寒暄主动查询”的工具选择规则关闭。默认2秒关系总截止与JEV默认1.2秒并行，仍受Prompt默认5秒截止；自定义10秒关系超时会超出Prompt等待窗口，需要协调配置。文档/JSON标签只供模型理解数据边界，不替代执行授权。

将档案/观察移到User是为了准确表达来源和允许刷新，本身不保证更省token：其内容仍随任务进入历史，可能重复累积。上述成本夹具明确关闭该功能；不能将夹具节省比例直接套到开启档案联动的会话。

真实模型的中文回复质量、工具必要性、纠错顺序、身份确认真实性、抗间接注入，以及真实JEV准确率仍需人工/行为评估。本轮未调用付费模型、真实JEV或外部数据库。手工验收见 [plan-manual-acceptance.md](plan-manual-acceptance.md)，当前位置规则以新版承接表为准。
