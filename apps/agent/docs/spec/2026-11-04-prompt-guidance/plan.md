## 目标与决策

共通事实、授权和完成核实归 base；能力触发与跨工具分工归插件 guidance；前置条件、参数、副作用和恢复归工具 description/schema。保留必要的调用点提醒，字段 schema 不替代执行层硬校验。

人格核心及完整 soul/boundaries/anti-goals 保留，JEV invariants 继续取自这些正文。动态事实与观察属于当前 User 背景；工具加载状态不能授予业务权限。ReActAgent 保持无状态，core 不依赖应用插件或 Prompt 契约，不改变 Plugin/Event 层边界。

英文化不等于扩大预算：生产 Prompt 总预算 12288、单节 8192、Persona 防御 200 保持原值。base 文本单测护栏由 600 调整为 1800；字符、生产保守预算与 tokenizer 代理值分别解释，见验证记录。

## 实施范围

1. 框架维护的 base、插件指导、工具/字段描述、任务联网提示、记忆包装、摘要、标题生成、JEV 判据和内置默认人格统一英文。用户当前语言决定回复/标题语言；不翻译用户正文、工作区规范、自定义人格、Skill 正文、第三方 MCP 描述和外部事实。
2. System 保留稳定共通规则、短能力发现/维护触发规则、人格核心和私有指令。删除启动时的 Skill 轻量目录采样（旧版也没有预注入正文），按需 list/search/read，避免目录快照陈旧和每轮固定负担。
3. 可选插件通过应用层契约提供工具范围指导；SessionRuntime 采样并将普通字符串交给 core 的工具目录。`tool_search` 返回完整范围指导与工具定义，仅在两者均完整保留时授予该 Run 的加载状态；core 不导入应用插件或 Prompt 契约。
4. Persona 人物关系事实不再在会话初始化时进入 System，按任务刷新并进入当前 User 上下文；演化观察作为会话冻结的背景数据进入 User，核心身份/边界和演化可用性保持稳定。防御仍条件触发，防御预算和总 Prompt 预算不放宽。
5. WebSearch 只在本轮 User 上下文报告时间、开关和查证深度，工具具体调用/来源规则在加载时交付。Memory 自动召回继续使用既有 Event/ACK 路径，不复制到 System。

## 交付位置与时机

| 来源 | 稳定 System | 按需或当轮交付 | 为什么放这里 |
|---|---|---|---|
| base/workspace/private | 共通规则、原文工作区规范、会话私有指令 | 既有refresh机制不变 | 稳定规则不随普通任务变动 |
| builtin-tools | 短文件/命令选择规则 | 常驻read/write/insert/bash的完整description/schema | 页码、覆盖、副作用、重试在调用点可见 |
| Memory | 使用/维护触发、当前事实优先和领域分工 | D(memory)交付纠错/停用/删除流程；自动召回仍走Event/ACK和Region | 不查询时无需带全套写入流程；自然使用及自主维护仍能触发 |
| Relationship | 缺身份/档案时查询，简单对话直接答 | D(relationship)交付查写协作；工具定义承接确认/方向/部分写入 | 不能仅因提及人名就查询；身份确认细节在写前提供 |
| Process | 短命令/服务分工与进程归属 | D(process)交付去重、ready、日志与重试；action规则在schema | 长任务才需要完整跟进流程 |
| Knowledge | 何时查库、写入必须服务任务 | D(knowledge)交付查读、引用、空结果与写入边界 | 无自动RAG；调用时看到来源验证和写库副作用 |
| Skill | 适用时发现，先读SKILL.md | D(skill)交付写入开关与作业验证；list/search按调用发现目录 | 删除常驻目录；未命中不证明不存在；不丢生成/演化状态确认 |
| MCP | 有配置时的短发现/信任规则 | 常驻目录/搜索/分发工具；外部schema照实返回 | 不把服务配置写成连接成功，也不翻译外部契约 |
| Persona | 核心身份/完整边界；可用时的演化触发 | U中的按任务人物快照、会话冻结观察、条件防御/重锚 | 事实与观察不再冒充System规则；刷新与JEV并行、错误独立 |
| WebSearch | 无专属常驻段 | U仅时间/开关/deep；工具description和结果notice承接来源/预算/数据边界 | 删除每轮重复调用示例；剩余预算由真实结果提供 |
| Blackboard | 无专属常驻段 | 延迟只读工具定义；摘要使用独立模型请求 | 本地状态按需读，摘要指令不塞主Agent |
| 标题/JEV/Skill生成 | 无主Agent常驻段 | 各自独立请求的英文System/判据 | 只在标题、判定或生成任务发生时付出成本 |
| persistence/runtime_update/user_input/agent | 无新增提示词 | 保持既有事件、存储、输入与执行适配路径 | 无具体提示词需求，不制造占位贡献 |

**D** 指工具搜索返回的 `scope_guidance`，**U** 指当前任务User上下文。完整 [104 条规则映射](plan-rule-mapping.md) 对每条旧规则登记所有者及验收场景，没有以“整体英文翻译”代替迁移完整性审阅。

范围规则在Session装配时冻结，只采样有真实延迟工具的有效插件。无效或超单节预算会阻止装配，避免工具可见而必要指引静默缺失。搜索输出裁剪后，指导和单项定义必须完整才能标为已加载；同步/异步均验证，可通过提高输出预算恢复。空指导不强制第三方插件采用此扩展。

## 运行边界与未解决事项

workspace 保持根目录可选来源和超限省略策略；此次增加原因日志，没有改为启动阻断，也没有递归加载子目录规范。用户可见降级状态仍需上层协议设计。

本轮完成语言、规则所有者、注入位置/时机和协议完整性调整。没有照搬Codex消息角色或引入新的WorldState/隐藏权限层。稳定前缀只保证应用产出的System不随普通任务改变，不承诺远端缓存。

每任务Persona关系刷新是显式启用时的后台读取，会增加读取次数；它不是模型主动调用relationship工具，也不会被“不为寒暄主动查询”的工具选择规则关闭。默认2秒关系总截止与JEV默认1.2秒并行，仍受Prompt默认5秒截止；自定义10秒关系超时会超出Prompt等待窗口，需要协调配置。文档/JSON标签只供模型理解数据边界，不替代执行授权。

将档案/观察移到User是为了准确表达来源和允许刷新，本身不保证更省token：其内容仍随任务进入历史，可能重复累积。验证记录中的成本夹具明确关闭该功能；不能将夹具节省比例直接套到开启档案联动的会话。

真实模型的中文回复质量、工具必要性、纠错顺序、身份确认真实性、抗间接注入，以及真实JEV准确率仍需人工/行为评估。本轮未调用付费模型、真实JEV或外部数据库。手工验收见 [验证记录](plan-validation.md)，规则归属以本专题映射表为准。
