颜色与层级

提供浅色、深色、跟随系统三种模式，默认跟随系统。选择保存在当前浏览器，系统主题变化会即时应用；手动选择后不受系统变化影响。所有模块、弹窗、菜单和关系画布使用同一组主题变量。深色模式与 TUI 色板一致；浅色模式保持中性灰与粉色的颜色职责。

布局与响应式

品牌图标采用展开书页与三个汇聚节点：书页表示知识沉淀，节点和分支表示资料、记忆与知识的关联。使用主题玫瑰色，顶栏以 28 px 展示；浏览器图标使用同一轮廓，跟随系统明暗配色。

视口 外壳布局 内容行为
≥ 992 px 顶栏高 64 px；侧栏宽 208 px，可收起至 64 px 页面内边距 28 / 32 / 40 px；内容区独立纵向滚动，导航保持原位。
768–991 px 顶栏高 64 px；侧栏自动切换为 64 px 图标导航 页面内边距 24 px；图标保留可访问名称。
≤ 767 px 顶栏高 56 px；模块导航置于顶栏下；知识库子导航为四列 页面内边距 24 / 18 / 32 px；筛选允许换行，弹窗接近全屏。
内容宽度 通用页面最大 1440 px；知识列表最大 1200 px 文档关联取消页面最大宽度限制，画布使用可用空间。
业务断点 部分表单、排版在 700 px 调整；阅读区在 1000 px 调整 外壳与组件按各自空间需求响应，不假定只有一组断点。

导航采用树形结构，主行和子行均为 40 px，字号 14 px，图标 18 px。展开侧栏通过子项缩进与浅色竖线表达层级，父级没有常驻背景或描边，仅当前页面高亮。知识库分类默认展开；父项文字进入上次访问页面，右侧箭头展开或收起分类，支持键盘 Enter / Space。图标描边统一 1.5 px；侧栏收起与窄屏图标栏保留四个分类快捷入口，取消缩进与层级线，父级图标 18 px、子级图标 16 px，点击区域仍为 40×40 px 并水平居中；整个知识库使用浅灰外层容器，四个子项再使用稍深的灰色内层容器，两层仅保留微弱灰色阴影，组内间隔 2 px、组间间隔 14 px，提示显示「知识库 › 分类名称」；手机常驻四列分类。桌面分类状态在当前页面会话中保留，切换到图标栏或手机仍显示全部分类入口，回到展开侧栏后恢复原状态。顶栏提供主题菜单。文档关联直接显示当前知识库画布，不重复知识库选择与搜索。

内容呈现

页面 信息结构 交互规则
记忆 自适应紧凑卡片；正文最多两行，状态、分类、用户和范围紧凑排列，更新时间右置 点击条目打开详情弹窗；多选模式独立处理，每页固定 15 条；桌面端每行 5 列，窄屏降为 2 列或 1 列，折叠或展开侧栏时保持列数与卡片顺序，只平滑改变卡片宽度。筛选与排序由服务端处理，批量操作只作用于当前页。
原始资料 自适应卡片；名称优先，辅助显示页数与派生知识数量 整张卡片可点击；不展示文件格式标签，不把正文加载状态放进卡片。
知识页面 自适应卡片；标题 + 最多两行摘要 不展示知识类型标签；类型仍可用于筛选。搜索匹配标题与摘要，不随正文加载改变。
知识卡片尺寸 列宽下限 260 px，空间不足时单列；间距 12 px 桌面内边距 16 × 18 px，窄屏 14 × 16 px；不设固定最小高度。
会话列表无逐条图标；单行标题截断，右侧显示相对时间；悬浮或聚焦可查看完整标题、最近对话和创建时间。首条提交后后台生成 AI 标题并保存；失败时保留原消息摘要，不阻塞对话。选中行使用中性底色，删除入口在悬浮或聚焦时显示。
对话内容Markdown 正文；思考与工具按任务默认折叠。输入框从首次显示起为一行，多行输入自动增高。消息定位提供搜索和上下跳转；新建不重连工作区，执行中拒绝删除；删除与放弃消息使用 360 px 确认弹窗，仅一句问题与两个操作。
筛选与返回 资料、知识页面分别保留搜索和类型条件 关闭阅读弹窗保留列表筛选、滚动位置并恢复原入口焦点；普通刷新不持久化会话筛选。

弹窗与阅读

场景 规格与信息 操作行为
通用弹窗 居中；标题和关闭按钮固定；正文独立滚动 仅有阅读内容时不添加确认按钮；需要提交时在底部提供明确的动作名称。
记忆详情 宽 640 px；原文、属性；来源标识与变更记录默认折叠，来源信息支持复制 修正、暂停或恢复、删除集中在弹窗；删除与放弃草稿使用同一弹窗的确认状态。
资料 / 知识阅读 宽度上限 1120 px；正文最大 780 px；高度上限 860 px 不设置“返回列表”或资料索引；通过关闭按钮、Esc 或遮罩返回。正文链接直接打开目标内容。
知识阅读工具 Markdown、代码、表格、引用、链接与可折叠文章目录 文章目录只导航当前正文。编辑位于阅读页，正文框初始高度随视口在 240–520 px 间调整，可垂直拖动加高；Ctrl / ⌘ + Enter 保存。
文档关联弹窗 宽度上限 720 px；文档名 + 内容来源 / 引用的页面 / 引用此内容的页面 只显示非空分组；点文档名直接阅读。缺失或同名歧义在该行说明并禁用打开。
关联信息边界 不重复正文摘要、探索路径、入链出链统计和二次操作面板 共同来源推测不混入引用关系；节点阅读和连线关系使用各自明确的弹窗。
未保存内容 编辑草稿与已保存内容分开处理 关闭、导航、浏览器返回前保护草稿；保存失败保留输入；刷新使用浏览器未保存提示。
资料危险操作 重新生成与移除放在“资料操作”菜单 重新生成说明覆盖影响；移除先获取影响预览，再明确确认。
离线示例使用原生 HTML 模拟交互，正式应用使用共用组件。

关系画布

要素 当前规则
画布入口 继承当前知识库，直接显示关系网；顶部不重复知识库选择、搜索和设置。
节点 16 px 彩色圆点，48 px 操作区域；标题最多两行，悬浮显示全文。资料、摘要、概念、实体分别使用绿、紫、玫瑰、橙色；不可用节点使用空心虚线圆点。
连线 默认从真实关系中选取少量连线，保留节点和连通分组，不显示全部交叉线。玫瑰色实线表示正文引用，绿色虚线表示来源；悬浮或聚焦节点展开它的全部关系与方向箭头。可切换全部连线，双向及多类型关系保留独立路径。
查看内容 点击节点或在节点上按 Enter 打开阅读弹窗；点击连线或在连线上按 Enter 打开关联弹窗并突出对应条目。
关注关系 精简模式仅显示当前节点的直接关联，离开后恢复少量连线；全部模式突出关联并淡化其他线。由详情进入画布时定位对应节点。
画布工具 缩放、平移、适应画布、重置布局及全部/精简连线；不显示缩略图。默认 87% 缩放。
视图状态 阅读弹窗关闭后保留视角与节点位置；拖动只改变当前画布会话，不写入知识内容。
当前布局 按真实关系运行固定的力布局；完成后停止运动。切换连线模式、悬浮和阅读不重新排列节点。

控件与反馈

操作层级

标准按钮、输入框、选择器高 36 px；图标按钮 36 × 36 px。关闭按钮与画布控件使用各自的紧凑尺寸。

状态语义

生效中处理中需重试已停用

颜色辅助表达状态，文字必须独立可理解。危险提交使用 danger，普通阅读操作不使用警告色。

输入与选择

输入焦点使用品牌色边界和弱化外环；检索范围通过名称或占位文字明确。

设置与不可用

保存中防止重复提交；只读示例禁用写操作。开关应直接表达当前状态。

状态 呈现方式
加载 / 刷新 加载使用居中转圈动画和可访问的状态名称；刷新保留内容，不展示冗余刷新说明。报告导出单独管理状态，不触发整个页面加载。
空数据 / 无匹配 区分“还没有内容”与“没有匹配结果”；只在存在有效下一步时提供操作。
请求失败 在受影响区域显示具体错误与重试；不伪装成空数据。关联服务失败时仍可阅读和导入资料。
成功反馈 短操作使用 Toast；逐文件导入、检查和移除预览使用可持续阅读的结果区域。
质量检查 独立页面，用户主动开始后才请求服务；同一知识库内切换页面保留当前报告。

键盘与无障碍

要求 实现与验收
语义结构 导航使用 link，操作使用 button；当前页面标记 aria-current；弹窗使用独立且可读的名称。
键盘焦点 可交互元素提供可见焦点；图标操作提供 aria-label；关闭阅读弹窗后恢复入口焦点。
快捷键 对话 Enter 发送、Shift + Enter 换行；Enter 阅读图节点或查看连线；Ctrl / ⌘ + Enter 保存编辑；输入法组合输入期间不触发快捷操作。
Esc 关闭阅读弹窗；有草稿先确认。记忆的删除 / 放弃确认状态优先回到上一状态。
内容安全与可读性 Markdown 不执行原始 HTML，危险链接不作为可点击链接；长文换行，宽表格和代码块在自身区域滚动。
动效与适配 遵循 prefers-reduced-motion；窄屏不允许页面级横向溢出；错误和状态不能只靠颜色传达。

实现与边界

职责 当前约定
共用组件 packages/ui 提供主题、基础控件封装、弹窗、导航与草稿保护；外壳负责模块导航和滚动容器。
业务组件 memory-app、knowledge-app 与 chat-app 各自维护内容、筛选与操作；不相互引用业务实现，不为单一页面增加共享抽象。
示例与真实数据 记忆连接 Mem0，知识库连接 OpenKB，对话连接 Gateway；运行页面已移除示例入口。服务确认后更新列表，不将浏览器状态描述为真实保存。
能力边界 知识搜索是本地索引匹配；没有服务端全文搜索、语义搜索或大规模分页。重新生成可能覆盖人工修改，暂无历史恢复。
验收顺序 先受影响页面测试，再完整 WebUI 测试，最后类型检查、构建和 diff 检查；布局覆盖桌面、平板与手机视口。
维护原则 规范描述当前代码与已验证行为；实现调整后同步修订。尚未完成的能力明确标注，不把规划写成既有功能。
