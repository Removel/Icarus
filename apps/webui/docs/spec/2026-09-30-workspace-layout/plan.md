# WebUI 工作区布局

## 目标

参照 Semi Design Layout 的顶部栏、侧边导航和内容区组合，替换底部悬浮 Dock，让导航和业务内容分层，不改变记忆与知识库业务行为。

## 实现

- 通过共用 UI 包导出 Semi Layout，应用外壳使用 Header、嵌套 Layout、Sider 和 Content。
- 顶栏展示品牌、当前模块、快捷导航和记忆演示提示，不宣称后端已连接。
- 记忆与知识库内容区不重复展示模块大标题；记忆顶部保留用户、范围与添加操作，知识库顶部保留库选择与业务操作；一级标题仅供辅助技术读取。
- 桌面导航宽 208 px，可收起至 64 px；768–991 px 使用图标导航；小于 768 px 将导航放到顶栏下方。
- 仅主内容区滚动；保留模块挂载状态、地址栏路由、快捷键、记忆弹窗及关闭后的焦点和滚动恢复。
- 移除底部 Dock 与为其预留的大面积空白，右侧使用连续白色背景，不再套带外边距、边框与圆角的内容卡片。
- 记忆用户与作用范围筛选放在顶部操作行，移除重复总数和固定 Agent 名称；分类下拉框直接展示在搜索旁。

## 验收

- 390、768、1280 px 无横向溢出，导航与内容互不遮挡。
- 收起与展开侧栏不丢失搜索、筛选或编辑状态。
- 内容滚动时顶栏及导航保持位置，弹窗交互和深链接回归通过。
- WebUI 浏览器测试、类型检查、构建与 diff 检查通过。

## 边界

不改变接口、服务鉴权或数据接入状态；记忆继续使用 Demo 数据。
