# 记忆列表与详情弹窗

2026-09-30。替换记忆页的分类大区块、行内编辑和非遮罩侧栏；不改变 Mem0 接入边界，也不修改知识库模块。

## 使用路径

用户与作用范围常驻顶部，与添加记忆同行，不显示固定 Agent 名称或重复总数。正文使用连续紧凑列表，分类作为辅助标签并可在搜索旁直接筛选；更新时间排序作用于整个结果集。保留现有状态路由、搜索与批量启停；多选时整行使用复选框，不打开详情，批量操作分别显示可暂停与可恢复数量，完成后退出多选。

点击条目打开阅读态弹窗，正文为主体，状态与分类并入正文上方详情字段，与归属、有效期一起使用双列布局；字段名为 12 px 常规灰字，字段值为 14 px 半粗体，状态保留语义颜色。变更记录默认折叠，时间跟在行为描述后同行显示，使用灰字区分，空间不足时自动换行。修正在同一个弹窗内切换编辑态；底部左侧直接显示删除记忆，右侧保留暂停/恢复与修正内容。删除先进入确认态，不叠加第二个弹窗，取消删除返回原详情。

## 返回与草稿

关闭详情保留筛选、排序、滚动位置，并恢复打开条目的键盘焦点；条目被删除时焦点回到列表。地址栏保留条目 ID，支持刷新重开、浏览器前进返回与失效 ID 回退。

未保存修改在关闭、取消编辑和浏览器路由切换时需要确认；确认仍在原弹窗内展示，继续编辑保留草稿。刷新或离开页面触发浏览器原生未保存提示。Ctrl/Cmd + Enter 保存，输入法组合期间不拦截快捷键。

手机使用共用弹窗布局，四周至少保留 12 px；高度随内容伸缩，长正文独立滚动，标题和底部操作保持可用，短确认不强制铺满屏幕。业务数据由 Mem0 持久化；暂停使用过去有效期，恢复清空期限。2026-10-01 收尾补充了历史展示分页、属性变化标签与可展开的正文差异，见交付收尾计划。

使用记忆模块浏览器功能测试验证：连续列表与全局排序、筛选、多选启停、创建与修正、编辑校验、历史折叠、删除确认、Esc/遮罩关闭、未保存确认、深链接与返回、滚动和焦点恢复，以及窄屏详情与编辑。随后运行 WebUI 全套测试、类型检查、构建与差异检查。
