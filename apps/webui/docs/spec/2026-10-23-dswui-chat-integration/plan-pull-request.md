统一 WebUI 对话、记忆与知识库工作台，补齐会话管理、图片输入、按需联网搜索及来源引用。用户可在同一外壳中切换业务页面，发送图文或纯图片消息，并在回答中查看实际检索来源。

## 主要变更

- 统一 DSWUI 布局、主题与共享控件，完善手机侧栏、会话重命名、置顶、导出、多选及批量删除；新增 Agent/模型共享设置入口。
- 完善流式 Markdown、公式、代码操作、思考与工具时间线；增加历史缓存、长会话虚拟列表、延迟加载及静态资源预压缩。
- 接入图片选择、粘贴、拖入、上传进度与重试，提供缩略图和全屏缩放查看器；编辑历史消息或再次提问时恢复文字和图片。
- 联网搜索开关允许按需检索；规划模型可返回空计划以跳过搜索。展示真实查询、检索来源和成功抓取的页面，正文引用打开对应来源卡片。
- 优化模型、Gateway、记忆及知识服务失败提示；修复图片草稿绕过删除保护、导航后下拉弹层残留、批量操作后焦点恢复等回归。
- 暂时隐藏输入框中尚未接入控制接口的“深度思考”按钮。

## 部署与兼容性

1. 同步更新 Agent/Gateway 并重启 Gateway，以加载新增 RPC、搜索插件和图片路由；重新构建 WebUI。
2. 需要联网检索时配置服务端 ICARUS_WEB_SEARCH_API_KEY，可通过插件配置调整 Search/Fetch 端点；未配置或检索失败时给出提示并继续普通回答。
3. 共享设置写入现有服务端配置文件。运行中任务继续使用已加载配置；没有跨端变更通知或模型热切换。

旧提交调用可省略 request_options；没有新增数据库迁移。Gateway 沿用本机单用户边界，浏览器经 WebUI 同源鉴权代理。

## 已知边界与复核重点

- 搜索开启时，判定不检索仍需一次规划模型调用；规划失败会回退查询。请复核 core 插件上下文等待及其对其他客户端的影响。
- 配置 revision 检查与文件原子替换不等同于跨进程事务；请复核部署方式下的配置写入边界。
- 图片限制为 20 MiB，当前校验 MIME 和签名，未做完整解码或像素限制；incoming 暂存文件尚无自动回收机制。
- 历史虚拟化仅挂载可见消息，浏览器原生全文查找与选区受挂载范围限制；导出继续读取完整历史。
- 凭据编辑表单、历史分支及 Rela 接入留待后续实现。
