统一 WebUI 的对话、记忆、知识库与人物工作台，接入真实人物、档案、关系及圈子管理。用户可以保留对话与列表上下文，在同一外壳内阅读人物、编辑单项信息、管理成员，并从 relationship 工具结果进入人物档案。

## 主要变更

- 接入独立 relationship 应用包及同源代理；人物/圈子采用紧凑卡片与阅读弹窗，支持搜索、归档包含、游标分页、深链接、返回与键盘焦点恢复。提供人物、别名、档案、关系、圈子和成员的单项写入及未知结果保护；不自动重试写请求。
- 账户菜单统一知识库、记忆和人物入口。修复按钮交互时边框变化造成的位移，加载提示改为延迟显示的覆盖层；阅读弹窗保持外框稳定，使用卡片记录即时呈现身份并继续校验最新详情。统一人物/圈子弹窗的对齐、层级、主次操作和空状态，隐藏无用分页。
- 完善会话管理、共享设置、Markdown/公式/代码、图文输入和查看器、历史缓存与长会话阅读。新增浏览器本地最近五条成功连接的工作区路径，选择历史仅填入路径，连接仍由用户触发。
- 联网开关允许 Agent 按需调用 `web_search` / `web_fetch`，支持直接抓取和连续补搜；展示真实查询、浏览进度和累计来源。保持任务预算、取消、来源编号与历史快照稳定；静态资源预压缩，CI 保留诊断产物。
- rela 为 WebUI 可选依赖；开发/生产代理在服务端附加 Token，浏览器不持有服务凭据。修复 Gateway WebSocket 因代理路由下标变化转发到错误服务的问题；根启动器区分工作目录失效、解释器异常与版本不足。

## 配套范围与部署

Agent/Gateway 已有本分支配套提交：共享配置、会话标题、提交选项、公开执行事件、联网工具和图片资源接口。Rela 服务业务、Mem0/OpenKB 服务端与数据库未因本轮接入修改，没有新增数据库迁移。

同步更新并重启 Gateway，重新构建 WebUI。人物功能需要单独启动 `rela-mem`，配置服务端 `ICARUS_RELATIONSHIP_ENDPOINT` 和 `RELA_MEM_API_TOKEN`；rela 离线不阻止打开 WebUI。联网工具按需配置 `ICARUS_WEB_SEARCH_API_KEY`。

## 当前边界

- 人物关系图与最短路径视图尚未接入；圈子无单条读取接口，深链接按现有列表分页定位。人物档案不随对话工作区隔离。
