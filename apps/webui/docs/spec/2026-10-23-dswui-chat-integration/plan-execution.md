## 1. 交付目标与范围

把 Icarus 对话页改为接近 dswui / DeepSeek 的独立对话外观，通过现有 Gateway 执行真实对话。知识库与记忆从对话页设置区域进入，继续使用现有内部布局与接口。

本期必须完成：

- 对话作为默认首页，具有单个会话侧栏、欢迎页、消息区、输入卡片和设置区域。
- 会话列表、新建、删除、AI 标题、搜索、历史、实时回答、思考、工具和错误展示。
- 发送、排队、引导、停止、未知提交结果处理和断线恢复。
- 设置内的主题、工作区连接及知识库/记忆入口；管理页返回对话。
- 对话与管理页面样式隔离，浅深色、手机布局、键盘和草稿保护。
- 功能回归、视觉对照、构建检查、文档与交付记录。

本期不新增：

- 前端直连模型、供应商与 Key 配置、OpenAI 兼容代理、第二套会话持久化。
- 手动改名、跨端置顶、历史编辑重发、重新生成、历史分支、全文远程搜索。
- 可控制模型能力的思考/联网/强度开关、模型选择、上传解析、语音或多用户系统。
- 公式、导出、虚拟列表、搜索来源面板和新的动画依赖。现有 Markdown、代码高亮和复制继续保留。
- 知识库和记忆内部布局重做、无关服务端重构、现有数据迁移。

后续若纳入这些能力，先补对应任务与接口依据，再修订估算，不能用空按钮或替代语义冒充实现。
