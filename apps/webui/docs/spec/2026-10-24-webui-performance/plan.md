# WebUI 性能改造

参考：[DeepSeek 网页性能逆向调研](../../deepseek-performance-reverse-2026-10-23.md)。

逐项实施状态、未实施原因及后续纯 WebUI 候选见 [落地对照清单](plan-coverage.md)；
构建与测试结果见 [验证记录](plan-validation.md)。

## 范围

用户授权先实施纯 WebUI 改造。所有源码、依赖、测试与文档变更限定在 `apps/webui/`。
复用现有 WebSocket JSON-RPC、增量 RuntimeUpdate、历史游标和会话接口。
不改 Gateway、Agent、Plugin Runtime、模型提供层，不添加会话预创建、PoW、服务端分页、CDN 或后端缓存协议。

## 实施顺序

1. 记录生产构建基线和现有交互测试。
2. 使用已有 Markdown 语法体系识别顶层块；完成块 memo，增长的末块单独解析。
   流式未成形表格、围栏头、未闭合展示公式使用纯文本；增长代码块暂缓高亮。
   引用链接、脚注等跨块语义保留整篇解析；最终文本使用完整文档解析校准。
3. 对 80 个及以上展示行启用 TanStack 可变高度虚拟列表，稳定 ID、ResizeObserver 测量、
   transform 位移，关闭浏览器滚动锚定；小会话保留全量 DOM。
   单帧合并流式滚动，保留用户上滚、目录跳转与强制到底语义。
4. KaTeX、代码高亮、记忆与知识库模块按需加载；首次访问管理页后保留挂载，保存界面状态。
5. 构建时生成 Brotli/gzip 副本，WebUI 静态服务器协商压缩格式；保留已有鉴权、代理边界和缓存规则。
6. IndexedDB 仅作提前展示的缓存，不影响 RPC 发起；刷新后从序列 0 重新构建权威历史，
   同页切换沿用已有内存缓存与增量请求。缓存限 12 会话、7 天、单会话 200 万文本字符，
   3 秒超时，连续 3 次失败后本页停用。删除会话同步清除缓存，避免清理时重新写入。
7. 增加浏览器本地 `icarus.chat.history` Performance measure，包含数量和内存缓存命中标记，
   不记录消息原文、不向外部上报。依次运行针对性浏览器/静态服务测试、完整 WebUI 测试、类型/构建/差异检查。

## 验收

- 增量到达不修改已冻结标题与段落的 DOM；最终更正文案、引用、公式、表格、代码仍正确。
- 数百条不同高度的消息只挂载可视范围及预留行；目录可定位尚未挂载的消息。
- 阅读上文不被新输出拖走；回到底部、窗口缩放、历史缓存切换行为稳定。
- 持久缓存失败、阻塞或过期不阻塞服务端历史；服务端数据覆盖旧快照。
- 压缩响应解压后与原件逐字节一致，遵守 q 值、HEAD、鉴权与 immutable 缓存。
- 构建体积与测试结果见 [plan-validation.md](plan-validation.md)。不将 DeepSeek 的实测数字当作本项目收益。

## 明确边界

完整长会话仍通过现有分页接口拉取并在内存重建；虚拟化降低 DOM/渲染开销，
不改变后端传输量。单个很长的 Markdown 块仍需重解析其增长尾部；这不是任意语法的逐字符增量解析器。
虚拟列表中离开可视范围的行会卸载，浏览器原生页面查找和整页选区仅覆盖当前挂载消息；
完整会话导出仍从历史数据生成。
