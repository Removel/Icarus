# 手动记忆与工作台修复验收

2026-10-01。

## 修复原因

WebUI 新增表单原先写死 `workspace:icarus`，并从列表第一条记录选择用户，可能将记忆保存到当前 Agent 无法匹配的归属或范围。新增表单现在通过只读 Gateway `memory.get_context` 获取配置中的用户、Agent 和规范化工作区范围。没有配置时保留草稿、停止保存，原文写入仍为 `infer: false`。

真实验收还发现，自动召回从 UserInput 到上下文确认总共只有 1 秒，首次连接开销可能耗尽预算。MemoryPlugin 默认改为 5 秒，可配置范围为 1–30000 毫秒；保留超时取消、终态放行和迟到上下文拒绝。没有通过模型供应商分支或 Hook 绕过现有分层。

## 界面和整理

- 记忆使用紧凑卡片网格，分类、范围与状态颜色各自表达信息，点击打开详情；旧无效范围会提示修正，详情可按当前配置重新添加，原记录保留。
- 会话管理改为侧栏，消息区域独立滚动，输入框固定；阅读历史时不自动跳底，可显式回到最新消息。键盘发送遵守执行中的禁用条件。
- 知识库子导航常驻并增大字号、点击区域；手机一行四项。知识库选择框约 180 px，搜索框最多 280 px。
- 检查操作位于选择知识库行下方；下方专门展示报告标题、完整空状态和报告列表。报告弹窗不会覆盖其他模块。
- 新增记忆表单拆为 MemoryCreate；会话状态与连接拆为 useChatSession；消息滚动拆为 ChatTranscript；记忆和对话复用公共 Gateway 客户端。
- 只读示例仅在开发模式按需加载，生产构建排除示例内容与入口；生产产物测试核对此边界。清理 README 中失效的服务地址环境变量说明。

## 使用

升级需同时更新 WebUI 和 Agent Gateway。新记忆默认全局；项目专用内容选择「指定工作区」，输入对话页所用的服务端绝对路径。旧记录归属或范围不匹配时，在详情使用「按当前配置重新添加」，核对新记忆后再删除旧记录。当前 Mem0 更新接口不支持原地修改身份，因此不自动迁移或删除用户原数据。
