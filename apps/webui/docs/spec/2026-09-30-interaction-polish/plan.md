# WebUI 交互与阅读完善

依据 2026-09-30 布局审阅与后续反馈，使用连续白色工作区，优先修复内容丢失与不稳定行为，再改善首屏与阅读效率。

## 实施

- 知识正文编辑和新增记忆共用未保存保护；应用内导航先确认再变更位置。浏览器前进／返回取消时恢复原历史位置，刷新使用原生提示。新增记忆在同一弹窗确认，支持 Ctrl/Cmd + Enter 保存。
- 知识标题和摘要以服务索引为准，正文读取不改变搜索候选。页面与资料分别按知识库保存筛选；支持单独移除条件。记忆清除筛选保留当前状态标签。
- 记忆多选使用统一操作栏替换搜索工具栏，整行对应一个复选框；全选仅作用于当前结果，暂停与恢复分别显示实际受影响数量。完成操作、改变筛选／状态或离开模块后清空并退出多选；取消与 Esc 返回浏览，保留筛选并恢复入口焦点。
- 手机知识导航保留三个标签，刷新和质量检查移入更多；资料使用分行条目。记忆归属控件收紧，手机搜索独占一行，筛选与排序置于下一行，辅助信息至少 12 px。共用样式提供系统字体回退，避免主题字体缺失时正文退回衬线字体。
- 阅读弱化模块标题与管理操作，减少正文外框；平板和手机仍可展开内容索引。安全 Markdown 渲染保留代码块、表格、列表、引用、链接；相同首个一级标题去重，文章目录只滚动正文，不改应用路由；知识双链只打开可解析对象。
- 快捷导航自动聚焦，支持上下键、Enter 与 Esc；设计规范移出业务导航。内部跳转使用右箭头，报告优先呈现处理结果与受影响页面，服务细节可展开。
- 搜索图标距左边缘 12 px，与文字间隔 8 px；聚焦仅使用输入框外层圆角高亮，避免内部矩形轮廓叠加。
- 共用弹窗居中展示，统一标题、关闭按钮、表单留白与底部操作区；长内容仅在正文区滚动，标题和操作保持可见。手机保留 12 px 边距，双列表单改为单列，短确认按内容高度展示。新建、导入和报告使用适合内容的宽度；导入清单展示文件大小，报告取消重复滚动容器。

## 验证

pytest 浏览器功能用例覆盖草稿确认／继续／放弃／保存、六类知识离开路径、筛选连续性、搜索稳定、360／390／768 px 标签与资料、阅读索引、Markdown 与危险 HTML、快捷导航和记忆首屏位置；随后执行 WebUI 全套测试、类型检查、构建与 diff 检查。浏览器使用测试服务响应，真实 OpenKB 连通性单独说明。
