# 记忆与知识：关系探索页

> 历史设计实验记录。独立实验入口已在“证据地图”正式迁移时移除；知识页现以 `2026-09-29-evidence-map/plan.md` 为产品方案，本文的示例数据和实验入口说明不再适用。

2026-09-29 · 独立设计实验入口：`/content-study.html`。原版业务页面保持不变。

用户确认保留中心内容与周边关系节点的展示方向。本次整理搜索、筛选、跳转、返回及阅读规则，不将实验页改成自由拖拽图谱，也不增加语义推理能力。

## 1. 展示与操作

- 中心卡片显示当前对象、真实摘录及阅读动作。
- 周边节点展示一层关系；点击切换关注点，不同时打开阅读弹窗。
- 记忆原句是末端对象，点击直接打开详情。
- 阅读或修正使用现有 Semi Modal，关闭后回到原探索或搜索位置。
- 记忆与知识分别保留浏览状态和页面滚动位置，底部应用切换不沿用另一页的滚动偏移。
- 沿用 Semi Universe 主题、底部导航、控件与卡片样式。界面不再展示“从这里出发”“继续探索”等重复引导句，保留内容、关系依据、数量、状态与必要错误信息。

## 2. 搜索与结果视图

两页搜索框常驻。输入非空查询或在输入框按 Enter 进入结果视图；知识页“全部内容”也能打开结果视图。查询是当前示例数据上的实时文本匹配，不是语义搜索。

| 操作 | 行为 |
| --- | --- |
| 清空搜索词 | 保持结果视图，展示当前条件下的全部结果 |
| 返回关系／Esc | 清除查询与结果类型筛选，返回原分类或知识中心，保留近邻页码 |
| 选择记忆结果 | 打开该原句详情；关闭后保留查询与结果列表 |
| 选择知识／资料结果 | 设为探索中心，退出结果视图，保留来路 |
| 重置筛选 | 只恢复状态或类型默认值，不清查询，不改变用户、范围或知识库 |

结果视图由独立状态控制，不能把“查询为空”当作退出条件。分类／关注点与结果视图分别保存；搜索期间关系区域隐藏但保持挂载，避免返回时丢失近邻页码。

搜索忽略首尾空白及大小写。结果列表中的按钮支持 Tab 与 Enter；不默认激活第一项。Esc 按最上层交互处理，不穿透下拉、详情或编辑确认；输入法组合期间不拦截搜索快捷键。

## 3. 记忆：身份、范围与状态

记忆数据先按用户隔离，再按范围和状态产生同一候选集合。分类、分类计数、原句与搜索结果都由该集合派生。

范围：
- **Icarus 工作区（含全局）**：当前用户的 `workspace:icarus` 与 `global`。
- **仅全局**：当前用户的 `global`，不表示聚合所有工作区。

状态：
- **生效中**：`!isExpired(item)`，默认选择。
- **已停用**：`expiration_date === '1970-01-01'`。
- **已过期**：已失效且不是停用哨兵日期。
- **全部状态**：不限制生命周期。

失效记录通过状态筛选访问，不另设重复的归档区域；在“全部状态”下仍显示停用／过期标记。有效期判断与原版共用 `isExpired`。

分类来自已有 `metadata.category`，只表示探索位置，不是额外的搜索过滤器。搜索覆盖当前用户、范围和状态下的正文与分类，可以从分类 A 找到分类 B 的原句；关闭详情保留结果，返回关系仍位于分类 A。

切用户或范围会回到分类总览，清查询和临时详情，状态恢复生效中。切状态保留查询；当前分类没有符合条件的记录时返回总览。范围或分类变化会重置近邻分页。

根级用户节点是静态信息，不提供无效果的返回按钮；分类下的上游节点才承担返回总览动作。

## 4. 知识：来源关系与来路

只使用示例中真实存在的来源声明：
- 知识页面 → 资料：该页面引用资料。
- 资料 → 知识页面：该页面引用当前资料。
- 知识页面 → 同源知识：两者引用至少一份共同资料，节点显示共同资料名称。

共同来源不是语义相似、推荐或模型推理。资料中心左侧没有已知上游时留白，不制造节点填满画面。

来源声明与资料可用性分别处理：页面没有来源声明时显示“未关联来源”；声明存在但对象缺失时保留文件名并标记“来源不可用”，不生成可点击的假对象。

### 查找与类型筛选

查询覆盖当前知识库的页面标题／正文，以及资料文件名／可用正文。结果视图提供“全部／知识／资料”，该类型条件只过滤候选列表，不能隐藏中心或切断关系图。

“全部内容”代替原先的“换个起点”，包括所有页面与资料，未被任何页面引用的资料也能到达。页面以 `path`、资料以 `hash` 标识，不以显示名称充当 ID。

失败、处理中或没有可用正文的资料仍可按名称定位，并显示实际状态，但不把演示失败说明当原文提供阅读。只有 `phase === 'ready'` 且正文非空时才允许阅读与正文匹配。

### 跳转与返回

图节点、搜索结果与全部内容列表共用同一个关注点跳转：
- 新目标追加到探索路径；重复选择当前目标不追加，但正常退出搜索并聚焦中心。
- 返回按钮删除最后一站；点击来路中的站点截断到该站，不创建新的历史。
- 关闭结果视图或阅读不改变路径。
- 再次经过此前对象可以形成路径循环，但不复制数据对象。

切知识库清理旧路径、查询、类型筛选和阅读状态。默认选择首篇页面；没有页面时选择首份资料；两者都没有才显示空库。默认首项不表示智能推荐。

本轮仍是页内探索路径：入口只在初始化时读取 `#knowledge`，不承诺浏览器前进／后退、深链接或刷新恢复。正式接入需要单独把这些状态纳入业务路由。

## 5. 关系布局与分页

桌面保留左侧上游、中心、右侧近邻的固定角色，手机改为当前内容、上游、近邻的纵向分支。对象用按钮或静态信息卡表达，不依赖拖拽、悬停或颜色辨认。

每侧最多四个节点，超出后按侧分页，显示当前范围与总量。顺序沿用来源数组，不使用未解释的排序分数。切中心、分类或上下文重置分页；打开并退出搜索不改变当前页码。

卡片采用普通布局流，舞台随内容高度扩展，不再将所有节点绝对定位到固定 520px 内。`RelationStage` 用 `ResizeObserver` 读取中心与实际可见节点的位置绘制连线；连线与节点来自同一分页切片。窄屏隐藏 SVG，保留分支线、关系标签及分页入口。

标题可换行；周边摘要适度截断，完整原句／正文通过详情可达。焦点和悬停均有可见反馈，遵循减少动效偏好。不新增分类配色，保留中性连线与现有强调色。

## 6. 阅读与修正

记忆详情保留原文、分类、身份、范围、有效状态和默认折叠的历史。修改只作用于选中的 ID：去除正文首尾空白、拒绝空内容，真正发生修改时记录旧正文与更新时间；无变化保存不产生空历史。

未保存退出区分两个意图：
- 取消编辑后放弃：丢弃草稿，留在该条只读详情。
- 关闭详情后放弃：丢弃草稿并关闭弹窗。
- 继续编辑／确认状态下按 Esc：保留草稿，返回编辑。

编辑期间不能通过遮罩直接丢弃内容。保存后即使原结果不再匹配查询，详情也不突然消失；关闭时若原按钮已不存在，焦点回到搜索输入或中心标题。

知识全文使用约 840px 的 Modal。展开来源后在同一弹窗内切换资料，返回恢复知识页面的阅读位置；不伪造段落定位。新一次阅读统一重置临时来源展开与滚动缓存，关闭后回到中心阅读按钮。

## 7. 文件、启动与边界

实现位于 `apps/shell/src/design-study/`：
- `ContentStudy.tsx`：独立入口与应用切换。
- `MemoryStudy.tsx`：记忆范围、搜索、分类与修正。
- `KnowledgeStudy.tsx`：知识候选、来源关系、路径与阅读。
- `RelationStage.tsx`：布局测量、装饰连线与按侧分页，不解释业务关系。
- `study.css`：仅作用于实验页的样式。

复用原有 UI、数据类型、示例数据、`Reading`、`excerpt`、`isExpired` 与日期格式化，不改共享控件契约或原版业务页面。

在 `apps/webui` 启动 `pnpm dev`，访问：
- `http://127.0.0.1:5173/content-study.html`
- `http://127.0.0.1:5173/content-study.html#knowledge`

原版入口仍为 `http://127.0.0.1:5173/`。实验页管理链接返回原版。

本页只有内存示例数据，修改刷新即恢复；不接模型、后端图谱、真实检索与持久化服务。正式的批量管理、导入和删除仍属于原版业务页。本轮不调整 Vite 多入口发布配置，因此常规 `pnpm build` 仅回归原版产物，不能代替实验入口的实际浏览器验证。

## 8. 验证

专项测试位于 `test/apps/shell/design_study/test_content_study.py`，复用 pytest 与 Python Playwright。缺失来源、资料独占库、不可读资料、长文本与大量近邻通过测试浏览器的模块响应注入，不修改正式示例数据。

```sh

pnpm typecheck
pnpm build
git diff --check
```

Windows 未安装 Playwright Chromium 时可按项目既有方式使用 `WEBUI_BROWSER_CHANNEL=msedge`。需另外查看桌面与手机的实际截图，核对节点与连线、输入框、阅读弹窗及窄屏溢出；不能只以编译或测试通过代替视觉验收。
