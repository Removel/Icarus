# Icarus WebUI

统一的 Icarus 外壳，包含「记忆」「知识库」与「对话」工作台，分别对接 Mem0、OpenKB 和 Agent Gateway。记忆数据由服务保存，刷新重新读取；对话支持会话历史、Markdown 富文本、流式文本、工具状态与取消；新建会话立即进入列表，切换时保留列表滚动位置。浏览器功能测试使用可控服务响应，生产入口另有真实 HTTP/WebSocket 代理测试。

界面按任务区分：记忆使用自适应紧凑卡片网格，用户与作用范围常驻，分类作为辅助标签和筛选；点击条目打开详情弹窗，修正、启停和删除集中在弹窗内。所选条目写入地址栏，刷新从服务重新读取对应详情；关闭弹窗保留筛选、排序、滚动位置并恢复列表焦点。知识库左侧按「原始资料」「知识页面」「文档关联」「质量检查」分区，默认进入资料页。资料负责导入与查看派生知识，资料与知识页统一采用紧凑的自适应文档卡片，以标题和摘要或派生数量为主；详情使用阅读弹窗；文档关联使用 React Flow 画布，也可从详情定位到对应节点。

对话局部复用 Semi 的代码高亮与 `AIChatDialogue.Reasoning`，保留现有会话、队列、任务引导与滚动控制。围栏代码提供语言标签、横向滚动和复制；完整回答可复制原始 Markdown。思考明细支持折叠，重新展开不重播已显示的流式文本；历史思考默认折叠。代码高亮支持 JavaScript、TypeScript、Python、Bash、JSON、HTML 和 CSS，其他语言按纯文本展示。复制需要浏览器允许访问剪贴板，失败时显示提示。

## 启动

需要 Node.js 22.12+ 和 pnpm 10.32.1。在 `apps/webui` 执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://127.0.0.1:5173>。可直接访问 `/#/memory/all`和 `/#/knowledge/sources`。知识库从服务读取数据，支持搜索、类型筛选、长文阅读、来源跳转和知识关联。

开发服务将 `/api/v1` 代理至 `http://127.0.0.1:7566`，并从仓库根目录 `.env`（或进程环境）读取 `ICARUS_OPENKB_API_TOKEN`，仅在 Node 代理侧添加 Bearer 请求头。令牌不使用 `VITE_` 前缀，也不进入浏览器代码。修改令牌后需重启开发服务。后端须单独启动；使用 Docker 管理时，在仓库根目录执行 `icarus start openkb`。其他部署使用 `ICARUS_OPENKB_ENDPOINT` 指定服务地址，并在代理层处理授权。

开发服务同时把 `/api/mem0` 代理到 `127.0.0.1:8888`、`/rpc` 代理到 `127.0.0.1:8765`。通过 `ICARUS_MEM0_ENDPOINT`、`ICARUS_OPENKB_ENDPOINT`、`ICARUS_GATEWAY_ENDPOINT` 覆盖地址，Mem0 管理 Key 使用 `ICARUS_MEM0_API_KEY`。对话页填写服务端工作区绝对路径，连接后选择或新建会话。生产运行使用 `pnpm build` 和 `node --env-file=.env.local server/index.mjs`，完整配置、容器、验收、回滚和排障见 [部署说明](docs/deployment.md)。

## 通过 Icarus 控制面启动

WebUI 也可以作为仓库原生后台进程运行，由 `icarus` 统一管理（不使用 Docker）：

```sh
icarus install webui   # 安装依赖并构建 apps/shell/dist
icarus start webui     # 后台启动 node server/index.mjs
icarus status          # 与其他应用一起查看状态
icarus stop webui
```

启动配置来自仓库根 `.env`（同名进程环境变量优先）：`ICARUS_WEBUI_HOST`（默认 `127.0.0.1`）、`ICARUS_WEBUI_PORT`（默认 `8080`）、`ICARUS_WEBUI_USER`、`ICARUS_WEBUI_PASSWORD`，以及 `ICARUS_MEM0_ENDPOINT`、`ICARUS_OPENKB_ENDPOINT`、`ICARUS_GATEWAY_ENDPOINT` 与对应 `ICARUS_MEM0_API_KEY`、`ICARUS_OPENKB_API_TOKEN` 覆盖项。非回环 `ICARUS_WEBUI_HOST` 必须同时设置用户名与密码，否则启动器拒绝启动。`make webui-up` / `make webui-down` / `make webui-logs` 是对应的便捷入口。


## 这版可以体验什么

- 记忆：突出正文、以主题辅助色展示属性的卡片网格，服务端分页与更新时间排序；文本搜索、分类/作用范围/用户筛选、多选与批量暂停或恢复；详情弹窗先展示原文，再展示归属、有效期与记录来源，来源会话、执行、工作区和操作标识收进默认折叠的「来源信息」，支持复制；变更记录默认折叠。在同一弹窗内修正、启停、确认删除或放弃未保存修改。Esc、遮罩与关闭按钮可关闭详情，编辑草稿未保存时需确认；浏览器返回也保留草稿并询问是否放弃。手机使用接近全屏的详情弹窗。
- 知识库：页面标题与摘要来自服务索引，列表搜索不受正文是否加载影响；知识页面与资料列表分别保留搜索和类型条件。阅读支持 Markdown 代码块、表格、引用、列表、普通链接、知识双链与文章目录。正文编辑离开前保护草稿，关闭按钮、Esc、遮罩、内容链接跳转和浏览器返回都需要确认；刷新使用浏览器未保存提示。关闭详情保留列表筛选和滚动位置，从关联画布打开的详情关闭后保留画布视角和节点位置。导入会解析资料并生成知识，完成后展示逐文件结果。资料详情的「资料操作」菜单包含重新生成与移除；重新生成前展示覆盖风险和可追溯页面，移除前读取服务影响预览。资料列表展示沿来源声明链计算的派生知识数量，详情区分直接引用和经来源链派生；不再把浏览器正文读取状态放在列表中。关联接口失败时仍可阅读和导入资料。质量检查位于独立页面，只在点击「开始检查」后调用模型，同一知识库内切换分类或模块保留本次报告，不会因打开页面重复执行。
- 文档关联：使用开源 [xyflow / React Flow](https://github.com/xyflow/xyflow)（MIT）与 [d3-force](https://github.com/d3/d3-force)（ISC），按需加载双链网状图。小圆点按资料、摘要、概念、实体着色，依据链接自动布局，包含独立页面；支持滚轮／触控缩放、拖动节点、平移、适应画布和重置布局。缩小时收起标签，悬停或键盘聚焦时在节点旁显示完整标题，并柔和突出直接邻居与连线；切换节点保持布局和视角稳定，不弹出悬浮预览卡片。高亮过渡遵循减少动效设置。实线表示正文引用，虚线表示声明来源；聚焦节点时显示箭头，双向引用分别保留方向。点击节点或按 Enter 阅读，点击连线查看关联详情；详情保留服务提供的名称、类型、描述、入链／出链数量和来源声明，以及资料格式、页数、标识、文档名称、来源路径与正文状态。较长的路径与原始字段在「更多字段」中展开，正文继续在阅读弹窗展示。关系仍按内容来源、引用的页面、引用此内容的页面分组，不从共同来源推测语义关系。布局计算后停止运动，节点位置与缩放保留在当前画布会话，不改变知识内容或服务数据。

  图谱首次打开、定位节点和重置布局采用 87% 缩放；「适应画布」仍根据内容自动调整。概念、摘要、资料、实体分别使用玫瑰、紫、绿、橙色；引用线为玫瑰色实线，来源线为绿色虚线，颜色随主题变化，悬停时提高对应关系的对比度。

- 设计规范独立保存于 [docs/design-system.html](docs/design-system.html)，可直接用浏览器离线打开。文件内置样式和交互示例，不依赖 CDN 或后端；不属于应用路由，不进入 Vite 生产构建。部署仅使用 `apps/shell/dist/`。

外壳采用 Semi UI `Layout.Header / Sider / Content`：顶部展示品牌和当前模块；桌面左侧常驻导航可收起，768–991 px 使用图标导航，手机导航置于顶部栏下方。知识库使用树形分组，展开侧栏通过子项缩进和浅色竖线表达层级；主项与子项均为 40 px 行高、14 px 字号和 18 px 图标。分类默认展开，父项文字进入上次访问页面，右侧箭头可展开或收起分类，仅当前页面高亮。收起侧栏与窄屏图标栏保留四个分类快捷入口，移除缩进与层级线；父级图标 18 px、子级图标 16 px，点击区域仍为 40×40 px 并水平居中；浅灰外层容器包住整个知识库，四个子项再放在稍深的灰色内层容器中，两层仅保留微弱灰色阴影，组内间隔为 2 px、组间间隔为 14 px，悬停提示包含所属知识库；手机使用一行四项分类。桌面分类展开状态在当前页面会话中保留，图标栏与手机始终显示四个分类入口。内容区独立滚动；对话页的会话列表和消息各自滚动，输入框固定，阅读历史时新消息不会抢走滚动位置。知识阅读通过关闭按钮或 Esc 返回原位置；资料按文件名和辅助信息分行展示。导入仅出现在资料列表。界面使用粉灰主题，标准控件为 36 px 高度；新增与修正都保护未保存内容，支持减少动效偏好。

对话执行区持续显示波浪状态，展开后最多容纳五条折叠明细，向上滚动暂停跟随、滚回底部恢复。发送、停止和引导位于输入框底部；空闲时 Enter 发送，执行中 Enter 加入本页队列，Shift + Enter 换行。引导使用当前任务的 session.steer；排队消息按顺序在任务结束后提交，可编辑、删除或暂停，停止任务也暂停队列。队列不跨页面刷新保存，离开及刷新前与草稿一起保护；放弃确认会真正清空未发送内容；删除对话与放弃消息的弹窗仅展示一句确认问题和两个操作。图谱保留全部节点，默认显示少量真实连线，悬浮或聚焦节点展开全部直接关联；可切换全部连线。资料、摘要、概念、实体使用随主题变化的绿、紫、玫瑰、橙色。

## 目录

```text
apps/shell/                导航、工作区外壳
packages/ui/               共用组件、主题变量与地址栏路由辅助
packages/memory-app/       Mem0 接口、记忆列表与详情
packages/knowledge-app/    OpenKB 接口、知识页面、资料列表与阅读工作区
packages/chat-app/         Gateway JSON-RPC、流式对话与会话管理
server/                   生产静态入口、代理、认证与真实服务检查
test/                     按 apps / packages 镜像组织的浏览器功能测试
docs/api-map.md            已核对的服务接口和接入差异
```

当前业务模块作为 workspace 包嵌入外壳，保留各自的筛选与编辑状态；它们没有调用或导入彼此的业务实现。生产入口面向单用户部署，支持 Basic 认证与服务端凭据代理；不支持 iframe 嵌入或多租户权限隔离。

## 验证

启动开发服务后，使用 uv 运行隔离的 pytest + Playwright 测试。首次使用默认 Chromium 时安装浏览器：

```sh
uv run --no-project --with-requirements test/requirements.txt python -m playwright install chromium
pnpm test
pnpm lint
pnpm format:check
pnpm typecheck
pnpm build
```

Windows 已安装 Edge 时，可在 PowerShell 设置 `$env:WEBUI_BROWSER_CHANNEL = 'msedge'` 后直接 `pnpm test`。用 `WEBUI_BASE_URL` 指定其他预览地址。单独验证记忆页：`pnpm test test/packages/memory_app`。

## 功能边界

知识库会上传真实文件并调用服务。读取失败与空列表分别展示；显式链接、来源声明和共同来源线索分别解释，不把共同来源当作语义支持。Markdown 不执行原始 HTML，危险协议链接不可点击；知识双链只跳转到能够确定的对象，当前没有段落级来源定位。列表搜索为本地标题／摘要或文件名匹配，未接服务端全文或语义搜索。

记忆暂停以过去的失效日期表示，恢复后变为长期有效；批量操作逐条提交并报告部分失败。清除筛选保留当前状态标签。记忆通过服务端接口分页，每页固定 15 条；桌面端每行 5 列，窄屏降为 2 列或 1 列，折叠或展开侧栏时保持卡片、顺序和列数，只平滑改变卡片宽度，不重新请求列表。搜索和排序覆盖服务的查询快照（最多 1000 条，超出时明确提示）。地址栏记录视图位置，不保存编辑草稿；记忆和知识业务数据分别由 Mem0、OpenKB 保存。正文编辑不修改服务管理的名称／摘要元数据；重新生成仍可能覆盖人工修改，目前没有历史版本恢复。检查报告由 OpenKB 保存在知识库中，质量检查页按每页 10 份展示，支持详情、Markdown 导出和确认删除。记忆历史每页 10 条，正文差异可展开全文；旧历史缺少属性快照时保留通用更新标签。Agent 断线后恢复历史，不自动重发输入；结果未知时需核对历史，显式重试复用提交 ID，幂等范围为同一 Gateway 进程。知识操作的流式进度、大规模分页和服务端搜索仍待完善。
