# Icarus WebUI · 交互 Demo

统一的 Icarus 外壳，重构后的「记忆」与「知识库」工作台。用于评审视觉、信息架构和操作流程；当前使用内存示例数据，没有连接 Mem0、OpenKB 或模型服务，刷新恢复初始内容。

界面按任务区分：记忆以可阅读条目按分类分组，修正与启停就地完成；知识库把「知识页面」与「原始资料」分成两条路径，阅读在宽幅工作区完成。数据状态仍保存在内存中，但当前视图（模块、分类、知识库、选中的记忆或页面）写入地址栏，刷新和浏览器返回可以恢复视图，业务数据本身仍会重置。

## 启动

需要 Node.js 22.12+ 和 pnpm 10.32.1。在 `apps/webui` 执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://127.0.0.1:5173>。可直接访问 `/#/memory/all`、`/#/knowledge/pages` 和 `/#/design`；`Ctrl/Cmd + K` 打开快捷导航。

## 这版可以体验什么

- 记忆：按分类分组的条目列表；文本搜索、分类/作用范围/用户筛选、更新时间排序、多选与批量暂停或恢复；条目内直接修正、暂停与恢复；非遮罩详情展示有效期和变更记录；删除确认。
- 知识库：知识页面以真实正文摘录呈现，打开后进入阅读工作区，可编辑正文并跳转来源；原始资料以紧凑列表呈现，显示格式、处理状态和关联知识页面数，可就地重新编译或打开原文；来源与知识页面可以互相跳转；来源关联视图用共同来源推导关系；质量检查展示预设示例报告；导入演示与资料移除确认。
- 设计规范：颜色、控件高度与状态、内容呈现规则。

桌面端以单块内容画布承载内容，底部浮动导航切换应用，内容区独立滚动；知识阅读使用左索引、主正文、来源引用的宽幅布局。手机宽度使用单列内容、底部导航和独立阅读视图，页面自然滚动。界面使用 Semi UI 的 Universe Design 主题，控件统一为 36 px 高度，样式集中在共用组件包和一个工作区布局文件中，旧的叠加布局已移除。记忆筛选默认收起，支持减少动效偏好。

## 目录

```text
apps/shell/                导航、工作区外壳、设计规范页
packages/ui/               共用组件、主题变量与地址栏路由辅助
packages/memory-app/       记忆页面及其示例数据
packages/knowledge-app/    知识页面、资料列表、阅读工作区及示例数据
test/                     按 apps / packages 镜像组织的浏览器功能测试
docs/api-map.md            已核对的服务接口和接入差异
```

当前业务模块作为 workspace 包嵌入外壳，保留各自的筛选与编辑状态；它们没有调用或导入彼此的业务实现。此 Demo 尚未实现独立前端部署、iframe 嵌入或服务鉴权。

## 验证

启动开发服务后，使用 uv 运行隔离的 pytest + Playwright 测试。首次使用默认 Chromium 时安装浏览器：

```sh
uv run --no-project --with-requirements test/requirements.txt python -m playwright install chromium
pnpm test
pnpm typecheck
pnpm build
```

Windows 已安装 Edge 时，可在 PowerShell 设置 `$env:WEBUI_BROWSER_CHANNEL = 'msedge'` 后直接 `pnpm test`。用 `WEBUI_BASE_URL` 指定其他预览地址。单独验证记忆页：`pnpm test test/packages/memory_app`。

## 演示边界

文件只读取名称与大小，不上传、不解析；编译、检查报告和来源关联为预设推导，不调用任何服务。新导入的资料只有文件元信息，正文标记为尚未解析，关联知识页面数为零，导入不会生成真实知识页面。阅读视图只处理标题、段落和简单列表，不是完整 Markdown 渲染器。搜索为当前列表文本筛选。

暂停使用以过去的失效日期表示，恢复后变为长期有效；批量操作只作用于当前筛选结果，筛选或分类变化时会清空选择。地址栏只记录视图位置，不保存新建的记忆、页面或资料，刷新后回到示例数据；地址中不存在的对象会退回对应列表。接入时需依据服务真实状态、删除影响预览、段落级来源定位、认证和错误返回替换这些演示行为，详见接口映射。
