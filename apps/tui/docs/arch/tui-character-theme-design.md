# TUI Character Theme Design｜TUI 角色主题设计

## 目标

在保留黑色终端底色和开发工具可读性的前提下，让 Icarus TUI 具有参考角色的视觉辨识度。
本次只调整品牌展示、色彩语义和视觉层级，不改变消息、队列或 Runtime 行为。

## 视觉语言

- 灰、黑、白构成界面主体，用中性明度层级区分内容、表面和执行区域；
- 羽翼浅粉只用于 Icarus 身份和当前输入焦点，是稳定的角色颜色锚点；
- 用户消息使用亮银灰，不与 Icarus 共用角色色；
- Tool、任务执行过程和 Queue 使用石墨灰与钢灰，不引入金色；
- 运行中状态使用灰色，避免把处理中状态误表达为警告或品牌内容；
- 低饱和绿色只表示成功或 Ready，低饱和红色只表示失败、取消和危险；
- 绿色和红色只落在必要的状态文字上，不大面积染色 Tool 卡片或其他容器。

## 色板

| 职责 | 色值 | 用途 |
|---|---|---|
| 主背景 | `#0c0c0e` | Screen 和主要留白区域 |
| 普通表面 | `#131315` | 欢迎卡、Tool、Queue 和状态栏 |
| 输入表面 | `#1c1c1f` | Composer |
| 中性边框 | `#4b4b51` | 欢迎卡、Queue 和普通容器边界 |
| 正文 | `#f1f1f2` | 对话正文和高优先级内容 |
| 次要文字 | `#97979e` | Workspace、帮助、运行中状态和辅助信息 |
| 用户亮银灰 | `#b8b8bf` | User 标签和消息边线 |
| Tool 钢灰 | `#626269` | Tool 边线和执行信息强调 |
| Icarus 浅粉 | `#e0a8b6` | Logo、Icarus 标签与边线、Composer 焦点 |
| 成功状态 | `#75bd92` | `completed`、`Ready` 等成功状态文字 |
| 失败状态 | `#db737f` | `failed`、`cancelled` 和错误状态文字 |

主题不再定义或使用暖金色。主背景、普通表面和输入表面必须保持中性，不添加粉色倾向。

## Logo 与响应式边界

欢迎卡在宽度大于 70 且高度大于 20 的终端展示用户提供的 8 行 ASCII Logo。窄屏或短屏隐藏
完整 Logo，显示紧凑的 `Icarus` 标题，优先保留 Conversation、Queue 和 Composer 空间。

## 组件映射

| 组件 | 颜色语义 |
|---|---|
| 应用标题、欢迎 Logo、Assistant 标签与边线 | Icarus 浅粉 |
| Composer 边框、提示符和焦点 | Icarus 浅粉 |
| User 标签与边线 | 用户亮银灰 |
| Tool 面板 | 普通表面、Tool 钢灰边线、灰色执行信息 |
| Tool 运行中、Queue 标题和内容 | 灰阶 |
| Tool 成功、Ready | 仅状态文字使用低饱和绿色 |
| Tool 失败、Agent Error、Task failed/cancelled | 仅必要状态文字使用低饱和红色 |
| Workspace、帮助文案、普通状态 | 次要文字灰 |

## 信息层级

用户消息和 Tool 都属于中性色区域，但不能依赖文字内容才能区分：

- User 保持透明背景，使用较亮的银灰标签与左边线，视觉上属于对话内容；
- Tool 使用深灰面板、中等明度的钢灰左边线和 `◆` 标记，视觉上属于任务执行；
- 两者采用温和明度差，不为增强区分额外引入蓝、黄或其他新色相；
- Queue 延续 Tool 的执行语义，使用灰色标题、边界和内容；
- Tool 的最终成功或失败只改变状态文字颜色，Tool 摘要和容器继续保持灰阶。

这一映射使颜色职责保持稳定：粉色回答“谁是 Icarus”，灰阶回答“内容属于对话还是执行”，
绿色和红色回答“最终状态是什么”。

## 改动边界

本次改动只包括：

- 调整 `apps/tui/src/styles.tcss` 的主题变量与组件颜色映射；
- 更新受影响的 TUI SVG 快照；
- 同步本设计文档。

本次不调整 Widget 结构、布局、文案、消息类型、Event、输入队列或 Runtime 行为。

## 验收

- 完整 Logo 在 100 列常规终端中不截断；
- 58 列窄屏和 12 行短屏隐藏完整 Logo，不挤压主要交互区域；
- 页面主体第一视觉印象是灰、黑、白，而不是粉色界面；
- Logo、Icarus 回复和 Composer 焦点形成连续但克制的角色色锚点；
- User 与 Tool 即使不读取文字，也能通过亮银灰边线和深灰执行面板区分；
- Tool 运行中、Queue 和滚动条不出现暖金色；
- running、completed、failed 三种 Tool 状态通过文字和局部状态色均可区分；
- Tool 成功只改变状态文字；失败与取消足够醒目，但不大面积染红；
- 宽屏、窄屏、短屏以及 running、success、failed 快照保持可读；
- TUI 全量测试、视觉快照、`compileall` 和 `git diff --check` 全部通过，并人工检查实际 SVG。
